# Anshumaan Khare - Portfolio Website

A modern, high-performance developer portfolio built with **HTML5, CSS3, Tailwind CSS, and interactive JavaScript animations**, showcasing engineering projects, cloud architectures, and production suites.

## 🌟 Featured Project Highlight

### **ILoveMyOfficeWorks: Office Productivity Suite**
- **Repository**: [github.com/Anshumaankhare2403/ILoveMyOfficeWorks](https://github.com/Anshumaankhare2403/ILoveMyOfficeWorks)
- **Architecture**:
  - **35 Tools across 7 Suites**: PDF management, document conversion (PDF ↔ Word/Excel/PPT/TXT), live editing & digital signing, image processing, security & encryption, file organization, and smart batch processing.
  - **Client-Side Privacy Engine**: Zero-server upload workflow ensuring user files remain within the browser sandbox/local device memory during supported operations.
  - **Cross-Platform**: Accessible via web application, desktop client, and mobile versions.
  - **Focus Areas**: Document Processing, Office Productivity, File Organization, Data Privacy, Client-Side Security.

---

## 🛠️ Tech Stack & Features

- **Frontend Core**: HTML5, Modern CSS3, Tailwind CSS (CDN & custom utility configurations)
- **Interactive Animations**:
  - Dynamic Star & Constellation particle canvas with cursor interaction
  - Typing effect for roles and engineering specialties
  - 3D perspective tilt effect on profile photo
  - IntersectionObserver animated counters for metrics (35+ tools, 7 suites, 5+ certs, 10% speedup, 100% privacy)
  - Interactive project category filters
  - Spotlight flashlight glow effect on project cards
  - ILoveMyOfficeWorks interactive 35-tool deep-dive modal
  - Embedded PDF resume viewer with 1-click download
  - Toast notification feedback system & 1-click clipboard copy
  - Smooth light / dark theme toggle with localStorage persistence
- **Responsive**: Fully optimized for mobile, tablet, and widescreen desktop displays

## 🚀 Running Locally

### Option 1: Direct in Browser
Simply open `index.html` in any web browser.

### Option 2: Using Vite
```bash
npm install
npm run dev
```

### Option 3: Using any static server
```bash
npx serve .
# or
python -m http.server 3000
```
