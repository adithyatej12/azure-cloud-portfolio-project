# Rubika C — Portfolio Website

A responsive, single-page personal portfolio built with HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `rubika-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension and click **Go Live**.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `rubika-portfolio`).
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will display your published website link.

## Personal details
The portfolio content is based on the resume supplied for this task. Review your contact details, dates, CGPA, project details and profile links before publishing.
